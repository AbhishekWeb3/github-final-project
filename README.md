## Simple Interest Calculator

A calculator that calculates simple interest given the principal amount, annual rate of interest, and time period in years.

### Input

- `p` – Principal amount
- `t` – Time period in years
- `r` – Annual rate of interest

### Output

Simple Interest = (p × t × r) / 100

### Formula

```text
Simple Interest = (p * t * r) / 100
```

### Purpose

This project provides a simple Bash-based calculator to help users calculate simple interest easily.

### How to use

Run the Bash script:

```bash
bash simple-interest.sh
```

Enter the principal amount, time period, and annual interest rate when prompted.
